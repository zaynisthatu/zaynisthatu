### 🚀 Featured Projects
- 🔗 **[incident-01-cpu-throttling](https://github.com/zaynisthatu/incident-01-cpu-throttling)**
  <br/> *Kubernetes case study on a real 12-service app: at 500 concurrent users, 0% failed requests yet the app was fully unusable — CPU throttling was silently queuing every request. Diagnosed via `kubectl top`, fixed by raising the CPU limit 200m → 400m: p95 latency 7.21s → 3.12s, throughput nearly doubled.*
